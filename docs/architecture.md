# System & Agent Architecture

## 1. System Architecture

```text
React Frontend (Vite + Tailwind CSS + Recharts + Lucide)
            │
            ▼ HTTP / REST (JWT Auth)
FastAPI Backend (Pydantic DTOs + Dependency Injection)
            │
            ▼ Orchestration Engine
Agentic Graph (7-Stage Pipeline)
┌────────────────────────────────────────────────────────┐
│ 1. Document Agent          (Type & Date Detection)     │
│ 2. Extraction Agent        (Structured Fact Extraction)│
│ 3. Evidence Engine         (FACT/UNCERTAIN/MISSING)    │
│ 4. Timeline Agent          (Chronological Milestones)  │
│ 5. Appointment Agent       (Prep Checklists)           │
│ 6. Follow-up Agent         (Admin Reminders)           │
│ 7. Doctor Briefing Agent   (Care Briefing Synthesis)   │
└────────────────────────────────────────────────────────┘
            │
            ▼ Human-in-the-Loop Barrier
Physician / Coordinator Review (Approve / Edit / Reject)
            │
            ▼ SQLAlchemy ORM
PostgreSQL Relational Storage (Traceable Facts & Audit Logs)
```

## 2. Mandatory Safety Boundary & Non-Diagnostic Scope

The platform is strictly bounded as an **administrative care navigation and evidence extraction system**.
It is mathematically and operationally prohibited from:
- Formulating medical diagnoses or clinical predictions.
- Suggesting or prescribing medications.
- Adjusting medication dosages.
- Ordering diagnostic clinical tests.
- Recommending clinical treatments or surgical procedures.
- Overriding attending physician judgment.

All generated outputs are stamped with:
`NOTICE: Generated by AI. Requires human review. Strictly non-diagnostic and non-prescriptive.`

## 3. Evidence & Uncertainty Invariants

1. **FACT**: Verbatim quote exists in source text with explicit document coordinates.
2. **UNCERTAIN**: Text in document is ambiguous, contains caveats, or references outside facilities.
3. **MISSING**: Required administrative documentation (such as a signed specialist referral slip) cannot be found in uploaded archive records.
4. **ASSUMPTION**: Inferred by AI; explicitly tagged and prevented from ever presenting as confirmed fact.

## 4. Security & Role-Based Access Control (RBAC)

- **CARE_COORDINATOR**: Document intake, fact verification, prep coordination, administrative follow-up tracking.
- **CLINICIAN**: Evidence verification, doctor briefing review, official clinical sign-off / amendment.
- **PATIENT**: Read-only timeline review, appointment preparation instructions, reminder alerts.
- **ADMIN**: User registry management, security parameters, tamper-evident audit logs.
